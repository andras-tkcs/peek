Google Org Sign-In Checklist

Two checks that need a real Google Workspace. Everything else about the feature is tested in CI against a fake Google issuer. Plan: docs/plans/google-org-signup-plan.md.

Before implementation

Nothing. /implement can start right away.

After implementation, before the pull request merges

Do these on a Peek server running the feature branch (for example mise run run behind a public HTTPS URL, or a staging deployment). The client secret is typed only into Peek's own Settings page, never into chat or the pull request.

1. Create the Google OAuth client and turn on Google org sign-in

about 15 min

Report back: paste "ma1 pass" or the exact error text into the pull request.

2. Sign in with an org account and a personal account

about 10 min

Report back: paste "ma2 pass" or note which step differed into the pull request.
